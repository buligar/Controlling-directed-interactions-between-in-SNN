# Карты направленности GC/PDC/DTF

Сеть моделируется без предварительного разгона: запись начинается в `t=0`.
Параметр `duration` задаёт одновременно длительность симуляции и записи.
Например, `--duration 10` даёт 10 с активности, а не 13 с с отбрасыванием
первых трёх секунд. В запись входит начальный переходный процесс сети.

Из каталога `v3` в окружении с Brian2, NumPy и Matplotlib:

```bash
python systematic_analysis.py
```

Новые результаты сохраняются в `direction_results_harmonic/`.
В manifest и метаданных отдельной спектрограммы записывается `burn_in_s=0.0`.
В `drive` указываются гармонический вход, пиковая амплитуда и начальная фаза 0.
Прежние `direction_results/` и `direction_results_calibrated/` содержат результаты
со стохастическим узкополосным входом. Текущий текст статьи опирается на этот
прежний перебор; для обновления статьи под гармонический ток нужен новый расчёт.

Основной перебор создаёт шесть графиков:

- `direction_GC.png`, `direction_PDC.png`, `direction_DTF.png` — диапазон 0–50 Гц;
- `direction_10Hz_GC.png`, `direction_10Hz_PDC.png`, `direction_10Hz_DTF.png` —
  полоса 8–12 Гц.

Сетка по умолчанию: амплитуды 0, 50, 100, 200 пА; частоты каждого внешнего
пуассоновского источника 0, 10, 50, 100 Гц; задержки −80, −40, −20, 0, 20,
40, 80 мс; seed 0–4. Всего 560 симуляций, четыре рабочих процесса.
Каждая запись длится 10 с с начала симуляции; шаг интегрирования — 0,5 мс.
Числа спайков суммируются в интервалы 10 мс (100 Гц).

Внешний ток стимулируемой популяции имеет вид `I(t) = A·sin(2πft)`.
Частота `f` по умолчанию равна 10 Гц, начальная фаза — 0.
Параметр `rhythm_amplitude` и аргументы `--amplitudes`/`--amplitude` задают
**пиковую амплитуду** A в пА. Стандартное отклонение синусоиды равно A/√2;
в прежней стохастической модели A задавал стандартное отклонение тока.
Синусоида вычисляется непосредственно в уравнении Brian2 на каждом шаге 0,5 мс.

В каждой популяции 50 нейронов с долями E/I 80/20. Сопротивление — 80 МОм,
постоянная времени — 20 мс, потенциалы покоя/сброса/порога —
−65/−70/−50 мВ. Внутренние скачки — ±3 мВ по типу пресинаптического
нейрона, внешние — +3 мВ. Постоянного тока, компенсации среднего
пуассоновского входа, гауссовского мембранного шума и рефрактерного периода нет.
В новом manifest это отражено полем `poisson_mean_compensated=false`.

Контакты взаимные. При неотрицательной задержке гармонический ток подаётся
на популяцию 1, при отрицательной — на популяцию 2. Модуль задержки задаёт
физическое время передачи в обоих межпопуляционных направлениях.
Внутрипопуляционные и внешние синапсы имеют нулевую задержку.
Случайные потоки пуассоновского входа и топологии сохраняют прежние позиции,
чтобы замена формы ритма не меняла их при том же seed.

Прямое сравнение `projection.delay = 40 * ms` и `projection.delay = -40 * ms`
в отдельном минимальном примере Brian2:

```bash
python check_negative_delay.py
```

В обоих запусках первая популяция выдаёт одинаковые заданные спайки;
пять связей передают их второй популяции, по одной связи на нейрон.
Знак передаётся непосредственно в Brian2, направление связей всегда 1 → 2.
В установленном Brian2 2.7.1 с NumPy backend оба значения принимаются:
при +40 мс ответ запаздывает на 40,1 мс, при −40 мс — на 0,1 мс.
Следовательно, в этом примере отрицательное значение не даёт опережения.
Добавочные 0,1 мс — шаг до следующей проверки порога нейрона.
Это наблюдаемое поведение данной версии, а не гарантия поддержки отрицательных
физических задержек. Скрипт печатает времена спайков и сохраняет сравнительный
растр `negative_delay_check/direct_delay_comparison.png` и NPZ с временами.

Спектрограммы отдельного условия сохраняются без полного перебора.
Например, 100 пА, задержка −40 мс, пуассоновский вход 50 Гц, seed 0:

```bash
python save_spectrogram.py --amplitude 100 --delay-ms -40 --noise 50 --seed 0 --duration 10 --window 2 --step 0.16
```

В каталоге `direction_results_harmonic/` сохраняются
`spectrogram_100pA_delay_-40ms_noise_50Hz_seed0.png` и NPZ
с исходными числами спайков, частотами, временами окон, спектрами и параметрами.
Дополнительно сохраняется `topology_seed_<seed>.png`: матрица знаковых весов
внутренних E/I-синапсов с подписями `p_intra=0.15`, `p_inter=0.05`
(значения по умолчанию). Рисунок строится по фактическим
синапсам симуляции и записывается в `--output-dir`. В NPZ матрицы весов
сохраняются как `synaptic_weights` и `external_weights` (мВ): строки —
пресинаптические источники, столбцы — постсинаптические нейроны.
Ось времени отсчитывается от начала симуляции.
Для записи 1 с и окна 0,5 с:

```bash
python save_spectrogram.py --duration 1 --window 0.5 --step 0.1
```

Каналы стандартизируются по всей записи. BIC выбирает порядок VAR среди 1–20,
а для окон используются `fit_var` и `connectivity_spectra` из
`population_connectivity.py`. Цвета показывают величины метрик без оконного
теста значимости. Недопустимые окна сохраняются как NaN.

В основном анализе значимость оценивается по 199 фазовым суррогатам
с поправкой по частотам, направлениям и трём метрикам. Полоса 8–12 Гц
использует тот же глобальный порог. Категория ячейки определяется строгим
большинством среди всех seed, включая неоцениваемые записи.

В `runs/` сохраняются классификации для продолжения перебора, в `manifest.json` —
настройки и контрольные суммы, в `runs.csv` — исходы. Программа проверяет
совпадение настроек и исходников перед повторным использованием результатов.

Повторная отрисовка прежних результатов без Brian2 и SciPy:

```bash
python systematic_analysis.py --report-only --output-dir direction_results
```
